# Lugard Vianney — Portfolio

Static HTML portfolio for GitHub/Vercel deployment.

## Structure

- `index.html` — portfolio page
- `styles.css` — styling and responsive layout
- `script.js` — lightweight navigation, scroll progress and reveal animations
- `assets/` — profile/workspace images
- `assets/projects/` — project/brand images

## Deployment

Upload the entire folder contents to a GitHub repository. Do not upload only `index.html`.

For Vercel, import the GitHub repository as a project. This is a static site: no build command is required and the output directory is the repository root.

All image references are relative paths, so the assets remain portable.
