# Lugard Vianney — Portfolio

A self-contained, responsive HTML portfolio for Lugard Vianney, Digital Marketing & Social Media Specialist.

## Files

- `index.html` — main portfolio page
- `style.css` — all visual styles and responsive layout
- `assets/` — portfolio images and processed logo assets
- `README.md` — this file

## How to use

1. Keep `index.html`, `style.css`, and the `assets` folder together.
2. Open `index.html` in any modern browser.
3. For online hosting, upload the whole folder to a static host such as GitHub Pages, Netlify, Vercel, or your preferred web host.

## Notes

- The two logo assets marked `transparent` were processed to remove their light background so they can sit naturally on the portfolio's panels.
- No performance figures were invented. The portfolio describes verified responsibilities and project scope rather than unsupported metrics.
- The page has a small built-in image lightbox and a mobile navigation menu. No JavaScript library is required.
- Google Fonts are referenced by the stylesheet. If the portfolio is opened offline without internet access, the browser will fall back to system fonts.

## Suggested deployment

For the F10 Studio application, upload the folder to a static host and submit the public URL alongside the portfolio PDF/other application materials if requested.
