# Lugard Vianney — Portfolio

A static, responsive portfolio for **Lugard Vianney — Digital Marketer & Social Media Manager**.

## Deploy

This is intentionally a plain HTML/CSS/JS site. There is **no npm install, framework, build command, or package manager** required.

### GitHub
1. Upload the contents of this folder to the repository root.
2. Commit the files.
3. Enable GitHub Pages if you want GitHub hosting, or import the repository into Vercel.

### Vercel
Import the repository and use the default settings. There is no build command and no output directory to configure.
